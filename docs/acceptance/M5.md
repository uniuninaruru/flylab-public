## Not executed / limitations

- macOS arm64; the RTX host; EGL with an NVIDIA driver.
- Cross-machine determinism: the same rollout gave different final-observation hashes in the cloud
  container (`9c67b1b5…`) and on the GitHub runner (`4e24a79d…`); cause not established. Same-seed
  reproducibility holds within each machine.
- Observation units (all `None`), other flybody tasks, `force_actuators=True`, FlyGym.
- Any decoder except `ZeroDecoder` (ENGINEERED null control). No neural input reaches the body.
- The 59-element action vector is the body model's actuator interface, not a biological motor map.
- M6 (closed loop) is blocked by design until the neural gate (M2/M3) passes, and by `OPEN_QUESTIONS.md` B1 (NumPy
  split between the neural and body stacks).
