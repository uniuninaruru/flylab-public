## Re-run after the independent audit (commit `f483118`)

Audit issues uniuninaruru/flylab#4–#13 were fixed (tests in `tests/audit/`). The real-data import
was repeated on the host with the stricter code: all 3 inputs match the registered upstream
size + MD5 (`matches_registry: true`), `verify` now also compares `edges.parquet` and
`neurons.parquet` with `graph.npz` and passes (`ok: true`, 0 problems), and the graph
fingerprint is unchanged (`4b2a5d76…`). Weights streaming 6.3 s, peak RSS 2.18 GiB.

## Not done / limitations

- Only the default node set was materialised on the host; `traced` and `flybrain_compat` are
  implemented and tested on synthetic data, and their node counts are measured in the manifest.
- Synapse signs, weight scaling and any treatment of the 112.6 M neuron → fragment rows are model
  decisions for PR-02 / later; this import stores only what the dataset provides.
- The 9-body difference to the paper's count is unexplained.
